# Contributing

1. Search existing issues and pull requests before starting work.
2. For larger changes, open an issue to discuss the proposal.
3. Create a branch, make a focused change, and run `mvn test` from the `seatendance` folder where possible.
4. Open a pull request explaining the changes and any tests you performed.
5. Never submit real student records, passwords, database files, or API keys.

For security concerns, contact the maintainers privately rather than publishing sensitive details in an issue.
